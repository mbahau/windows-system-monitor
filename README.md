# Windows System Monitor

`SysMonitor.exe` is a lightweight Windows system-monitoring utility.

## Download

Download the latest `SysMonitor.exe` from this repository and save it to a folder on your Windows computer.

## Run

Double-click `SysMonitor.exe` to start the application.

Windows may display a security warning for files downloaded from the internet. Only run the executable if you trust its source.

## Requirements

- Windows
- No separate installation is currently required

## Repository contents

- `SysMonitor.exe` — the application executable
